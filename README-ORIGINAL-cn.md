# learn_github_codespaces_basic_v1-project

配置开发环境是初学者最容易卡住的地方. 不同的操作系统, 冲突的软件版本, 缺失的路径设置, 这些问题足以在你写下第一行代码之前就消耗掉好几天. GitHub Codespaces 把整个开发环境搬到云端: 打开浏览器就有一台配置好的 Linux 机器, 本地什么都不用装.

这门课带你把这台云端机器真正用起来. 你会亲手启动, 停止和删除一个 Codespace, 认全它的界面, 然后在里面走通 Git 的核心工作流: 把改动 commit 并 push 到 GitHub, 从 main 拉分支, 通过 Pull Request 合并回去, 以及处理日常用分支时最容易卡住的那几个地方. 全程不需要敲一条 Git 命令.

深度定位在 basic 这一档: 目标是让你能独立完成一次真实的协作流程, 而不是精通 Git. 课程末尾还会讲清楚 Codespaces 怎么计费, 怎么给自己设预算上限, 并给出一个判断: 以后什么活该在本地做, 什么活该在云端做.
