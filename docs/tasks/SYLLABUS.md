# Syllabus

## 01-readup

Learn to work entirely in the browser with GitHub Codespaces: launch and manage a Codespace, find your way around the VS Code interface, commit and push your changes, run a full branch and Pull Request collaboration flow, clear up the branch situations that trip people up day to day, and read the compute and storage bills well enough to set yourself a monthly budget cap. By the end you can run a complete development cycle on your own, and decide whether a new task belongs on your local machine or in the cloud.
