# learn_github_codespaces_basic_v1-project

配置开发环境是初学者最容易卡住的地方. 不同的操作系统, 冲突的软件版本, 缺失的路径设置, 这些问题足以在你写下第一行代码之前就消耗掉好几天, 而手上只有 Windows 电脑的人被消耗得尤其厉害, 因为开发者工具这个世界基本长在 Unix 那一侧. GitHub Codespaces 把整个开发环境搬到云端: 打开浏览器就有一台配置好的 Linux 机器, 本地什么都不用装, 也就没有什么可配坏的.

这门课带你把这台机器真正用起来, 并在上面完成一个开发者每天都在做的那些事: 改代码, 让改动安全地留在 GitHub 上, 需要和别人协作时开分支走 Pull Request, 遇到分支状态不明时知道该看哪里. 深度定位在 basic 这一档, 目标是让你能独立走完一次真实的协作流程, 而不是精通 Git. 全程不需要敲一条 Git 命令, 但你走的和专业团队每天走的是同一套, 所以概念一旦建立起来, 将来换到本地的 VS Code, GitHub Desktop 或者命令行都能很快上手.

课程末尾还会讲清楚 Codespaces 怎么计费, 怎么给自己设一道预算上限, 并回答一个很实际的问题: 以后新任务该在本地做还是在云端做. 内容拆成 [examples/](examples/) 下一篇篇按编号排列的短教程, 从 01 那篇系列索引开始顺着读下来即可, 每篇都配了一张可以逐项打勾的自查清单. 学完还想继续往前走的话, 最后一篇也给了方向和可以直接拿去搜的关键字.
