# 认识 Codespaces 界面: 阅读练习

## 1. 目标

通读 Codespaces 界面导览教程, 认识界面里的顶部搜索栏, Activity Bar, Side Bar, Editor, Terminal, 底部面板和 AI 助手面板这几个主要区域, 建立起对整个 Codespaces 云端开发环境的基本方向感, 不再被密密麻麻的按钮和面板吓到.

这是一个纯阅读练习, 不需要写代码, 也不需要提交任何改动.

---

## 2. 要做的事情

1. 完整读一遍 Codespaces 界面导览教程, 不要跳段.
2. 如果手头有已经打开的 Codespace, 边读边对照实际界面, 依次找到教程里提到的 7 个区域: 顶部搜索栏, Activity Bar, Side Bar, Editor, Terminal, 底部面板 (OUTLINE 和 TIMELINE), AI 助手面板.
3. 在 Activity Bar 上点几个不同的图标, 观察 Side Bar 的内容如何随之切换.
4. 找到 Terminal 面板, 确认自己知道它在哪里, 以及怎么打开它 (菜单 View 下的 Terminal).
5. 读完后逐条对照下面的检查清单自查, 都确认清楚了再收尾.

**预计用时:** 15 到 20 分钟

---

## 3. 检查清单

- [ ] **通读教程**: 完整读完了 Codespaces 界面导览教程全文
- [ ] **顶部搜索栏**: 知道顶部搜索或命令栏的位置, 以及它能用来找文件, 找代码和执行命令
- [ ] **Activity Bar**: 知道左侧那一竖条图标是用来切换不同功能面板的
- [ ] **文件浏览器**: 知道点击 Activity Bar 里的文件夹图标, 能在 Side Bar 里浏览项目的文件和文件夹结构
- [ ] **Editor**: 知道中间最大的区域是编辑代码的地方, 支持多个文件同时以标签页打开
- [ ] **Terminal**: 知道底部有一个 Terminal, 也知道怎么打开它
- [ ] **心态调整**: 明白不需要一次性记住所有功能, 先掌握 File Explorer, Editor, Terminal 这三样最常用的, 其余用到时再学
