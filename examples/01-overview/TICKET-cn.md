# 读懂这门课的地图

## 1. 目标

这个 Task 只有一件事: 读一遍索引, 拿到整门课的全貌, 然后决定自己怎么走. 它没有任何要动手的操作, 也没有产出物. 但花这几分钟是值得的, 因为知道自己接下来要经过哪几块, 比闷头从头读起要少走很多回头路. 读完之后你也该心里有数: 这门课有没有一部分是你已经会的, 可以快速扫过去.

---

## 2. 要做的事情

1. 通读本 Task 的 README, 把这门课分成的三块内容加一篇收尾过一遍.
2. 对照每一组下面那几条说明, 判断哪些是你已经会的, 哪些是完全陌生的.
3. 决定自己的起点: 没有基础就从 02 顺着往下读, 已经用过 Codespaces 的可以直接从 05 那条 Git 主线开始.

**预计用时:** 5 到 10 分钟

---

## 3. 检查清单

- [ ] **说得出分块**: 你能说出这门课分成哪几块, 每块解决的是什么问题.
- [ ] **说得出起点**: 你能说出自己打算从哪一篇开始读, 以及为什么.
- [ ] **认得出重头戏**: 你能说出哪一组是这门课的核心, 也就是必须动手做完的那三篇.
